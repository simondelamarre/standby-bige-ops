# Security policy

## Reporting a vulnerability

Do not open a public issue. Use GitHub's private vulnerability reporting on this
repository ("Security" tab, "Report a vulnerability").

Include what you found, how to reproduce it and the version or commit you
tested. You will get an answer within 7 days.

## Supported versions

Only the latest release receives fixes while the project is below 1.0.

## Scope

In scope: the `standby` binary, the waiting page it serves, the schemas, and the
example deployments in this repository.

Out of scope: the cloud provider, the load balancer and the application put to
sleep.
